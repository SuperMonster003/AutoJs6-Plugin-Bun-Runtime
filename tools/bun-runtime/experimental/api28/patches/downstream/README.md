# Downstream backport patches

This directory is reserved for numbered patches reviewed against exact Bun
commit `34cbb9a40b4bd1bd767d134a7065e66c2432a676`.

It is intentionally empty. Adding a patch requires a corresponding entry in
`../series.lock.json` with its SHA-256, purpose, source relationship, affected
paths, license impact, and review/application evidence. Until that series is
complete, the experiment must remain `buildReady: false`.
