## 验收范围 (每轮 9 组, force-stop 前后各一轮)

1. environment, installed final APK, extracted runtime and supervisor integrity
2. signature permission, Wake discovery and activation
3. action/category discovery, explicit Binder, PluginInfo capabilities and repeated prewarm
4. JavaScript, TypeScript, Unicode and bounded streaming callbacks
5. all five checked-in samples including local HTTP fetch and file I/O
6. workspace archive project round trip, hostile archive and missing entry rejection
7. supervised timeout and output-limit reaping, localized summary and invalid request rejection
8. cancellation after readiness, supervised reaping and recovery
9. unbind and reconnect

探针是纯 Android/Java `Instrumentation`, 以 release 变体 androidTest APK 编译并使用 release 签名, 从主 APK 之外持有插件签名权限, 直接驱动生产 Binder;
每轮开始前硬断言 API 级别, 页大小, 安装版本, 安装后 base.apk SHA-256, 期望 ABI 集合以及 `nativeLibraryDir` 中运行时/监督器的 SHA-256 与字节数.
装有 AutoJs6 的三台真机使用私有权限名的探针 (AutoJs6 拥有 `org.autojs.permission.PLUGIN`), AVD 使用 AutoJs6 权限名的探针; 两者源码相同, 只有权限名不同.

## 生命周期与 M6 证据 (每台设备每轮均出现)

- `LIFECYCLE error=TIMEOUT|OUTPUT_LIMIT|CANCELLED childPid=... reaped=true exitCode=137 workspaceRemoved=true`: 三种终止均由监督器 SIGKILL 并回收, 每次运行的私有工作区随之删除.
- `TIMEOUT_SUMMARY`: 超时摘要按设备语言本地化 (Xiaomi 为中文, 其余为英文), 与十语言资源一致.
- `WORKSPACE files=3 bytes=549 root=.../cache/bun-executions/<run>/project`: 归档展开到私有工作区后以项目目录为工作目录执行, 相对 import 与 JSON import 成功.
- `HOSTILE_ARCHIVE`: 含 `../` 的归档与缺失入口被拒绝, 返回本地化的无效请求摘要, 随后单源码执行恢复.

## 边界

- No v0.1.0 upgrade path exists: v0.1.0 was never published, so the only user-facing upgrade is v0.2.0 to v0.2.2; it was exercised on two devices holding the published v0.2.0 APKs.
- Signed-APK acceptance was not repeated on native arm64 16 KiB hardware; the Samsung SM-A566B evidence binds a v0.2.1 development Debug APK, not these Release files.
- Native x86_64 large-page execution remains blocked; the x86_64 signed acceptance ran on a 4 KiB API 33 AVD.
- The black-box probe holds the plugin signature permission and drives the production Binder directly; it is not an AutoJs6 host round trip, and the workspace archive group packs its own ZIP because no released AutoJs6 sends project archives yet.
- The probe is compiled twice from the same source: devices carrying AutoJs6 (which owns org.autojs.permission.PLUGIN) use a private permission name, the AVD probe uses the AutoJs6 permission name.
- Official-source publication does not count as publication of patched APK/source assets.
