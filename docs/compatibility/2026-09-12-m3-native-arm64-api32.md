# M3: Samsung Fold4 原生 ARM64 Android 12L 验收

证据日期: 2026-09-12. G2, test-only 实验插件和独立应用探针, 非生产或 Release APK 验收.

## 结论和设备身份

Samsung Remote Test Lab Galaxy Z Fold4 **SM-F936U** 确实提供了本项目缺少的 **Android 12L / API 32 原生 ARM64** 环境. 网站和系统 release 字符串显示 Android 12, 但设备 `ro.build.version.sdk=32`; 两套 instrumentation 也独立硬断言 API 32, 不根据网站标签或机型推断版本.

| 实测字段 | 结果 |
|---|---|
| API / release 字符串 | `32` / `12` |
| primary ABI / kernel machine | `arm64-v8a` / `aarch64` |
| 页大小 | `4096`, shell getconf 和应用内 Os.sysconf 一致 |
| native bridge | `0`, 未使用 ARM 翻译 |
| 内核 | `5.10.81-android12-9-25063374-abF936USQS4AVII` |
| fingerprint | `samsung/q4qsqw/q4q:12/SP2A.220305.013/F936USQS4AVII:user/release-keys` |

使用用户预约的 `localhost:30008`, 未升级、重置、root 或修改系统页大小. 这是物理 ARM64 的 **4 KiB** 证据, 不是原生 16 KiB 验收.

九补丁 Bun `1.4.0+7b9ac2668` 通过两套分别运行的现有测试:

- 实际生产服务和共享 API 的完整现有 8 项 Binder instrumentation, 两轮 **16/16**. 见[独立 Binder 机器报告](2026-09-12-m3-native-arm64-api32-binder.json).
- 原有 29 项独立 test-only 应用探针, 两轮 **58/58**. 见[独立应用探针机器报告](2026-09-12-m3-native-arm64-api32-probes.json).

每套均在两轮之间 force-stop 并重建应用进程. 本轮设备测试没有失败、跳过或替换失败报告后的重试; 未修改定义、夹具、校验器、服务实现或资源限制.

## 验证范围

Binder 使用真实服务权限和相同八个测试方法, 覆盖安装的只读 payload、发现/元数据/预热、JS/TS 和样例执行、流式输出、无效请求、超时/取消/输出限制及 Wake 契约. 十条额外生命周期诊断均为 child reaped、exit 137、workspace removed: 六次 CANCELLED 为 310-315 ms, 两次 OUTPUT_LIMIT 均为 816 ms, 两次 TIMEOUT 为 3303-3306 ms. 这些是整个执行的 durationMillis, **不是纯终止耗时**, 均在既有 5000 ms 上限内.

应用探针在普通 UID 10328、`untrusted_app` 域、seccomp=2 中执行, 不使用 adb shell 直接运行 Bun 代替应用 seccomp 验证:

- 四个硬 FD 上限模式各两轮, 共 **8/8**. 先打开 FD 256, 将 soft/hard 从 `32768/32768` 同时降到 `128/128`, 恢复硬上限必须得到 EPERM. 四次同 PID 启动保留哨兵并设置 CLOEXEC; 四次 spawn 探针中的同步/异步 API 均不继承哨兵, 共八次子 API 观测. Java 应用和 supervisor 的上限保持 `32768/32768`. 本设备未加测试过滤器时 raw CLOEXEC 调用已返回 ENOSYS, 不宣称内核原生 close_range 成功. 新模式耗时 86-254 ms, 合计输出 521-848 bytes, 没有放宽预算.
- 原四次降低软上限并恢复的用例通过. 六次强制生命周期用例从请求终止到 supervisor 退出为 **301-302 ms**, child/supervisor 和私有工作目录均已回收.
- 六种 raw syscall 对照各两轮, 共 12 次 TRAP-to-ENOSYS 观测. `copy_file_range` 和 `pidfd_open` 各两次 EIO 控制的高层复制/等待探针通过, 不是六种 syscall 的全部高层验收.
- 48 项目录路径断言通过, 包括 12 次拒绝越界哨兵读取, 同时保留普通文件与根内链接服务. raw openat2 在过滤器前已不可用, 仍不计为首次高层 EIO/TRAP 触达.
- 内部 lchmod 的七个固定离线 CLI 对照各两轮, 共 14 次通过. KILL_THREAD 对照先观察 leader `Z/31`, 再回收剩余线程; 不把 SIGKILL 本身当作路径触达. 不据此扩大为公开 node:fs lchmod 或完整包管理器支持.
