# M3: API 29 / 32 原生 x86_64 版本覆盖补齐

证据日期: 2026-09-12. G2, 两个独立 test-only 套件, 非生产或 Release APK 验收.

## 结论与设备

九补丁 Bun `1.4.0+7b9ac2668` 在 API 29 和 API 32 的原生 x86_64 / 4096-byte 页 AVD 上, 现有完整 8 项插件 Binder 各两轮通过, 新增 **32/32**; 固定 25 项独立应用探针也各两轮通过, 新增 **100/100**. 两个套件分别归档, 不相互代替:

- [真实插件 Binder 机器报告](2026-09-12-m3-api29-api32-binder.json).
- [独立应用探针机器报告](2026-09-12-m3-api29-api32-probes.json).

| 本轮 AVD / 设备型号 | API | ABI / 实际页大小 | Binder 第一轮 / 第二轮 | 应用探针第一轮 / 第二轮 |
|---|---:|---|---|---|
| bun-m3-api29-x64-20260912 / Android SDK built for x86_64 | 29 | native x86_64 / 4096 bytes | 8/8 / 8/8 | 25/25 / 25/25 |
| bun-m3-api32-x64-20260912 / sdk_gphone64_x86_64 | 32 | native x86_64 / 4096 bytes | 8/8 / 8/8 | 25/25 / 25/25 |

API 29 为 Google APIs revision 13 镜像, kernel `4.14.175-gdbec1739`, native bridge=`0`. API 32 为 Google APIs revision 4 镜像, kernel `5.10.101-android12-9-00027-g1292f517889e-ab8602202`, 提供 `libndk_translation.so`, 但本轮安装并执行的是已核对摘要的 x86_64 ELF, primary ABI 与 kernel machine 均为 x86_64, 不是 ARM 翻译执行. 两环境均独立核对 shell `getconf PAGE_SIZE` 与应用中的页大小; 应用探针同时要求普通 application UID, `untrusted_app`, seccomp=2.

本轮开始时两个系统镜像已在磁盘上, 带有有效 SDK 包元数据, 创建和启动成功. 上次下载器失败仍保留在原报告, 不改写成当时成功, 也不将 E 盘清理未经验证地认定为原错误的唯一原因.

与[此前 API 28/30/31 的 Binder 记录](2026-09-12-m3-experimental-binder.md)合并, 现有套件已覆盖 API 28-32 五个 x86 版本, 每版本两轮, 合计 **80/80**. 加上其他 ABI/API 的原九环境矩阵, 当前累计十一环境 **176/176**; 这是分别绑定到实际 APK 的多批次证据, 不是声称同一最终 APK 重跑了全部环境. 历史 25 项探针的六环境 300/300 不改写; 本轮为两个新增 x86 环境的独立 100/100. Android 12 / API 31 与 Android 12L / API 32 分开记录.

## 有限语义结果

Binder 每轮覆盖安装后 native 摘要、发现/绑定/Wake/权限元数据、PluginInfo、预热、JS/TS/样例、流式输出、非法请求、超时/取消/输出超限及清理. 四轮共 20 条生命周期诊断, 整次执行耗时 314-3323 ms; 该数值不是纯终止延迟.

独立探针另外保留以下精确边界:

- 8 次降低 `RLIMIT_NOFILE` 软限制: 从 32768 降为 128, hard limit 仍为 32768, sentinel 保持 fd 256, `spawnSync` 与 `spawn` 子进程均不继承它, 原限制完整恢复. 不宣称 Android FD 70000 或降低 hard limit 已覆盖.
- 12 次忽略 SIGTERM 的强制生命周期回收全部通过, 从请求终止到监督器退出为 **302-304 ms**, child/supervisor 消失且 workspace 删除. 不扩展为任意 detached descendants 的监管.
- 24 次六目标 raw TRAP-to-ENOSYS 控制通过, 不能据此把六项全部算作高层 fallback 验收.
- 6 次 EIO-controlled 高层观测: 两个版本各两次 copy_file_range, 加上 API 32 两次 pidfd. **API 29 的两次 pidfd 都是 policy-gated**, EIO 注入仍观察到 ENOSYS; 虽然后续子进程等待和回收正确, 这两次不计高层 EIO 触达成功.
- 96 次目录路径断言通过, 包括 24 次越界哨兵请求拒绝, 普通文件和根内链接保持工作. 两版本 raw openat2 在测试过滤器前都已不可用, 仍没有高层首次 EIO/TRAP 触达证明.
- 内部 lchmod/fchmodat2 的七个固定离线 bare-link 对照共 28 次通过. 四次定向终止都先观察 owned leader 的 `Z/31/3 threads`, 再以已有 child handle 清理; 不把单独 SIGKILL 当作 SIGSYS 触达. 公开 node:fs lchmod 仍未导出, 不声称完整包管理器或 CLI 支持.

## 可重复归档与清理

新增 [archive-probe.mjs](../../tools/bun-runtime/experimental/api28/app-probe/archive-probe.mjs), 针对新运行重验当前源码 receipt、两轮完整原始 instrumentation 与 JSON 的一致性、所有语义断言、安装后摘要、同一环境身份及清理结果. 同镜像更换 UID/时间/目录不能计为新环境, 不同 APK build 不能混入同一归档. 归档保存原始文本及其摘要, 独占创建拒绝覆盖历史文件. 四组单元测试包含失败、缺轮次、源输入/字节漂移、原始文本不一致、崩溃、残留 UID 和重复环境等负向变体, 已接入构建 CI; 不宣称远程 CI 已运行.

每轮结束后 force-stop 并确认对应 UID 进程为 0; 两套件最终卸载后再次确认包不存在、UID 无进程. 独立 postflight 复核 API 29 的 Binder UID 10146 / probe UID 10148, API 32 的 Binder UID 10149 / probe UID 10151, 均为 0. 只关闭本轮新建并启动的 `emulator-5560` 与 `emulator-5562`, 保留 AVD 配置和镜像以便复测, 不删除或重置旧设备数据.

开场已有 `emulator-5554`, `emulator-5586`, `emulator-5588` 三台 AVD, 本轮未对其发送启动/停止/重置或测试安装命令. 结束复核时仅 `emulator-5554` 仍在线; 另外两台期间已离线, 其原因不在本任务中调查, 不宣称三台始终在线. 四台物理设备未用于本轮执行且仍在线.

## 未关闭的门禁

用户确认目前没有 Android 12L ARM64 设备, 因此 **ARM64 API 32 真机仍待验证**, 不能由本轮 x86 AVD 代替. 完整 syscall/SIGSYS/线程/高 FD/hard-limit/UNSHARE/watch/reload、剩余 API/OEM 矩阵、大页 JSC 压力与逐层 JIT 证据、最终签名 APK 及同 Release 对应源码发布仍分开推进. 本轮没有新增原生 16 KiB 设备证据或修改官方页大小防护.

正式插件仍要求 Android 13 / API 33, `distributionReady=false`. 官方 Bun、supervisor、大页候选、已发布资产和用户选定的目录回退方案均不变. 单源码 `--no-install`、无相对项目导入、无 AutoJs6 globals、无 Java bridge 及可信代码而非安全沙箱的合同不变. 本轮没有发布 Release.
